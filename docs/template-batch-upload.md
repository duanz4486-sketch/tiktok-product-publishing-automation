# 模板批量上传使用说明

这是当前已经跑通、可以优先给团队试用的入口。

## 适用场景

同一批产品使用同一个妙手参数模板，只替换标题和图片。例如：

- 同类目地毯批量上新
- 同类目非定制毛毯批量上新
- 同类目定制毛毯批量上新

## 前置准备

1. 在妙手里准备好对应模板产品。
2. 在网页「妙手账号管理」里保存妙手账号、App Key、App Secret 和模板 ID。
3. 在 `.env` 中配置 OSS 密钥。
4. 准备标题 Excel。
5. 准备图片 ZIP 或图片文件夹。

## Excel 要求

Excel 必须包含表头：

- `序号`
- `标题`

标题列也可以使用：

- `最终英文标题`
- `title`

匹配规则只看序号：

```text
Excel 序号 1 -> 图片子文件夹 1
Excel 序号 2 -> 图片子文件夹 2
Excel 序号 3 -> 图片子文件夹 3
```

Excel 文件名不需要和批次名、ZIP 文件名一致。

## 图片要求

图片来源可以是 ZIP，也可以是网页选择的大文件夹。

推荐结构：

```text
图片批次/
  1/
    1.jpg
    2.jpg
  2/
    1.jpg
    2.jpg
  3/
    1.jpg
```

规则：

- 子文件夹名称必须和 Excel 序号一致。
- `Thumbs.db` 会被自动忽略。
- 如果 Excel 有序号但没有图片文件夹，会记录失败：缺少图片文件夹。
- 如果图片有序号但 Excel 没有标题，会记录失败：缺少标题。
- 批次名、Excel 文件名、ZIP 文件名不参与匹配。

## 页面操作

1. 打开网页首页。
2. 选择妙手账号。
3. 选择产品模板：`大地毯`、`非定制毛毯` 或 `定制毛毯`。
4. 填写批次名。批次名只作为任务名称，方便查找。
5. 上传标题 Excel。
6. 上传图片 ZIP 或图片文件夹。
7. 勾选是否自动上传图片到 OSS。
8. 建议先勾选「先预检，不创建产品」测试匹配。
9. 确认无误后取消预检，正式开始处理。

## 处理结果

页面会显示：

- 总数量
- 已处理数量
- 成功 / 失败状态
- 图片数量
- TikTok ID
- 失败原因
- 本地日志路径

失败项目不会阻止其他产品继续处理。

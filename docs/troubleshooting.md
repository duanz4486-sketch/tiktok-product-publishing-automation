# 常见问题

## 系统自检有红色失败项

红色失败项代表模板批量上传缺少必需配置。优先按页面右侧的“处理方式”修正。

常见项：

- 没有 `.env`：复制 `.env.example` 为 `.env`，填写 OSS 密钥。
- 没有 `accounts.json`：复制 `accounts.example.json` 为 `accounts.json`，或在网页新增妙手账号。
- 妙手账号缺模板 ID：进入「妙手账号管理」重新识别或手动填写模板 ID。

命令行也可以运行：

```bash
python scripts/check_setup.py
```

如果这个命令返回 `ERROR`，先修复错误项，再启动网页。

## 网页打不开

检查：

1. 程序是否正在运行。
2. 端口是否正确，例如 `8002`。
3. 云服务器安全组是否放行 TCP `8002`。
4. 服务器系统防火墙是否放行 TCP `8002`。

## 创建任务失败：缺少图片文件夹

原因：Excel 里有这个序号，但图片 ZIP 或图片文件夹里没有同名子文件夹。

处理：

- 检查图片目录是否有 `1/`、`2/`、`3/` 这样的子文件夹。
- 确认子文件夹名字和 Excel 序号一致。

## 创建任务失败：缺少标题

原因：图片里有这个序号文件夹，但 Excel 里没有对应序号。

处理：

- 补齐 Excel 标题。
- 或删除不需要处理的图片子文件夹。

## 数字命名 ZIP 被识别错

当前规则不依赖 ZIP 文件名。ZIP 名字可以是数字。真正用于匹配的是 ZIP 解压后的子文件夹序号。

正确结构：

```text
541313.zip
  541313/
    1/
    2/
```

或：

```text
541313.zip
  1/
  2/
```

## OSS 上传失败

检查：

- `.env` 是否配置 `OSS_ACCESS_KEY_ID` 和 `OSS_ACCESS_KEY_SECRET`。
- RAM 用户是否有 OSS 写入权限。
- Bucket 是否允许读取生成后的图片 URL。
- 图片格式是否是支持格式。

## 妙手接口认证失败

检查：

- 妙手账号管理里的 App Key / App ID 是否正确。
- App Secret 是否正确。
- 这个 App 是否有商品相关接口权限。
- 当前妙手账号是否能访问对应店铺和模板。

## 模板找不到

模板批量上传目前需要三个模板：

- `大地毯`
- `非定制毛毯`
- `定制毛毯`

处理：

- 在妙手里确认模板产品存在。
- 在网页「妙手账号管理」里重新保存账号，让系统重新识别模板。
- 如果自动识别失败，可以手动填写模板 detailId。

## 仓库未选择

原因：对应店铺没有可用默认仓库，或者妙手返回的仓库列表为空。

处理：

- 进入妙手店铺设置，给店铺配置默认仓库。
- 再重新运行任务。

## 处理很慢

常见原因：

- 图片上传 OSS 需要时间。
- 妙手接口保存每个产品都需要等待。
- 图片数量多、网络慢、妙手接口响应慢。

处理：

- 先用少量产品预检。
- 图片压缩到合理大小。
- 确认服务器网络正常。
